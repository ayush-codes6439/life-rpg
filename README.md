k# ⚔️ Life RPG — Level Up Your Life

Turn real-world tasks into an epic RPG progression system. Earn XP, level up, build streaks, and unlock rewards.

## 🌐 Live Demo

- **Live App:** [https://])
- **Video Walkthrough:** [Link])

## ✨ Features

- 🔐 **User Authentication** — NextAuth + bcrypt
- 📜 **Quest System** — Create, complete, delete tasks
- ⚡ **RPG Progression** — Non-linear XP leveling
- 🎯 **4 Attributes** — Intellect, Strength, Vitality, Creativity
- 🔥 **Streaks** — Consecutive days tracking
- 🪙 **Economy** — Earn gold, buy from shop
- 🎉 **Celebrations** — Confetti + Level Up modal
- 📱 **Responsive** — Mobile to desktop
- ♿ **Accessible** — Keyboard navigable

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 16, React 19, TypeScript |
| Styling | Tailwind CSS v4, Framer Motion |
| Backend | Next.js API Routes |
| Database | PostgreSQL (Supabase) + Prisma |
| Auth | NextAuth.js |
| Effects | canvas-confetti |
| Deploy | Vercel |
